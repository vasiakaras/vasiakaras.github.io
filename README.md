# vkarasavva.com

Personal site of Vasileia Karasavva. Plain HTML and CSS with no build step; GitHub Pages serves it as-is (`.nojekyll`).

- `index.html` holds all the content
- `assets/style.css` holds the styles (light and dark)
- `assets/fonts/` holds the self-hosted Inter and Source Serif 4 fonts (SIL OFL)
- `assets/headshot.jpg` is the portrait

Preview locally: `python3 -m http.server` and open http://localhost:8000
